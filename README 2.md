# Five Nights: After Hours — Character & Custom Night Upgrade

## Play
Extract the ZIP and open `index.html` in a modern browser.

## Main nights
Play Nights 1–6 in order. Your progress is saved in the browser's local storage. Surviving Night 6 unlocks Custom Night.

## Custom Night
After beating Night 6, choose **CUSTOM NIGHT** from the main menu. Set Rusty, Vex, Peaches, and Grin from AI level 0–20. Level 0 disables that character for the round.

## Secret character
The Witness is a rare, original hidden apparition. Keep an eye on CAM 8 — VENT HUB. It may appear briefly on the feed.

## Controls
- C — raise/lower camera monitor
- A / D — left/right doors
- Q / E — left/right lights
- Click the right hallway to access the hidden vent
- Code 2234 unlocks the original secret powers

Unofficial fan-made browser horror prototype. This update adds a sixth night, a rare secret character, and a custom-night mode while retaining the existing office, cameras, power, secret vent, and fan animatronics.
